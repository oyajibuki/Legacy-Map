# 運用戦略レポート — WordPress

## 1. エグゼクティブサマリー

**現状リスク評価: D ランク（高リスク）**

世界の43%のWebサイトを動かすPHPスパゲッティです。グローバル変数・フック地獄・グローバル関数の混在という「最悪のコード」でありながら、最も成功したCMSという逆説。技術的負債は深刻ですが、エコシステムの巨大さが最大の資産です。

**今すぐ対応すべき3項目:**
1. WordPress・PHP・MySQLのバージョンを最新に保つ（セキュリティ最優先）
2. 使用していないプラグイン・テーマの即時削除
3. .htaccess / wp-config.phpのセキュリティ設定の見直し

---

## 2. そのまま使えるもの ✅

| モジュール | 状態 | 理由 |
|---|---|---|
| wp-content/ (テーマ・プラグイン) | 安全（管理次第） | コア本体から独立 |
| REST API (wp-json/) | 安全 | モダンな設計 |
| WordPress Cron (wp-cron.php) | 安全 | シンプルなスケジューラー |

---

## 3. 要注意エリア ⚠️

| ファイル/箇所 | リスク種別 | 影響度 | 対策 |
|---|---|---|---|
| wp-includes/ | グローバル関数の密林 | 高 | コアは変更禁止。フックで拡張 |
| functions.php | テーマごとの混沌 | 高 | 小さく保つ。プラグイン化推奨 |
| データベース直接操作 | SQLインジェクション | 致命的 | $wpdbのprepare()を必ず使う |
| wp-config.php | 設定ファイル露出 | 致命的 | webroot外に移動 |

---

## 4. 即時対応推奨項目 🚨

- **XML-RPC**: 無効化推奨（ブルートフォース攻撃の入口）
- **管理者ログイン**: /wp-admin/ への2要素認証の設定
- **ファイル権限**: wp-content/uploads/ への実行権限禁止
- **バックアップ**: UpdraftPlus等でのリアルタイムバックアップ設定

---

## 5. 運用ルール

- **コアは変更禁止**: WordPress本体は絶対に直接編集しない。アップデートで上書きされる
- **フックの活用**: add_action/add_filter でのみ拡張。コアへの直接変更は厳禁
- **セキュリティプラグイン**: Wordfence等の導入
