# 運用戦略レポート — Ruby 1.0

## 1. エグゼクティブサマリー

**現状リスク評価: C ランク（中リスク）**

1996年12月25日、Matzがクリスマスを選んでリリースしたRuby 1.0は、日本発で世界標準になった唯一のプログラミング言語の正式版です。v0.49から大幅に成熟しており、オブジェクト指向・イテレータ・例外処理が完成しています。

**今すぐ対応すべき3項目:**
1. 本番利用は即座にRuby 3.x系へ移行（Ruby 1.0はサポート終了）
2. 教育・研究目的での保存と活用の明確化
3. 依存ライブラリのEOL確認

---

## 2. そのまま使えるもの ✅

| モジュール | 状態 | 理由 |
|---|---|---|
| eval.c（インタープリタ） | 教育目的で安全 | 1.0として完成した実装 |
| string.c / array.c | 安全 | Rubyの基本データ型の実装 |
| Ruby文法定義 | 安全 | parse.yで厳密に定義 |

---

## 3. 要注意エリア ⚠️

| ファイル/箇所 | リスク種別 | 影響度 | 対策 |
|---|---|---|---|
| eval.c | 5000行超の神ファイル | 高 | 読み取り専用として扱う |
| メモリ管理 | 安全でないC API | 高 | 本番利用禁止 |
| 文字列処理 | マルチバイト未対応 | 高 | 日本語使用時は注意 |

---

## 4. 即時対応推奨項目 🚨

- **本番利用禁止**: セキュリティパッチなし。Ruby 3.3+を使用すること
- **研究活用**: Rubyの設計思想を学ぶ教材として、RubyKaigiやコミュニティでの活用推奨

---

## 5. 運用ルール

- **歴史的アーカイブ**: GitHub + タグ管理でv1.0の状態を永続保存
- **比較研究**: v0.49→v1.0→v3.xの進化を追うことでRuby設計思想の理解が深まる
