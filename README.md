# LegacyMap 🗺️

レガシーコードの依存関係・リスクを可視化し、AIが運用・移行戦略をレポートするツール。

## 機能

- **コード構造マップ** — ファイルの依存関係をforce-directedグラフで可視化
- **リスク色分け** — 黒（安全）/ 橙（要注意）/ 赤（危険）/ 鮮赤（緊急）
- **線の太さ** — ファイル間の依存度を表現
- **AI分析レポート** — Claude APIによる運用戦略・移行計画の自動生成

## 対応言語

TypeScript / JavaScript / Python / C / C++ / Go / Ruby / Java / Rust など

## セットアップ

```bash
npm install
npm run dev
```

`.env.local` に Anthropic API キーを設定:

```
ANTHROPIC_API_KEY=sk-ant-...
```

## 使い方

1. ブラウザで `http://localhost:3000` を開く
2. プロジェクトフォルダをドロップ（または選択）
3. 依存関係グラフが表示される
4. ノードをクリックでリスク詳細を確認
5. 「AI分析」ボタンで運用戦略・移行計画レポートを生成

## リスク判定基準

| レベル | 条件 |
|--------|------|
| 安全（黒） | リスク要因なし |
| 要注意（橙） | ファイル大・依存多・テストなし |
| 危険（赤） | EOL依存・大ファイル・高結合 |
| 緊急（鮮赤） | 循環依存・CVE・CoffeeScript等 |
